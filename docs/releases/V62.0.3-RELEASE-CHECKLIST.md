# BahnConnections V62.0.3 – Navigation und stabile Zugpanels

- Stabile Tooltip-Bindungen verhindern den Leaflet-Fehler beim erneuten Fokussieren ausgewählter Marker. Unbehandelte Browser-Ausnahmen sind ein verpflichtender Testfehler.

## Umfang
Enthält die Korrekturen aus V62.0.1 und V62.0.2: gemeinsamer Scrollbereich für Follow-HUD
und Zugdetails, alte Auswahl bei neuer Suche aufräumen, ausgewählte Fahrt bei Radar-Ausfällen
erhalten und fehlende Positionsgrundlage als pausiert kennzeichnen.
Zusätzlich öffnet die Zugauswahl aus PC-Planer und Verbindungsansicht das Fahrtpanel.
Die Auswahl setzt den aktiven Navigationsbereich auf Karte statt im PC-Suchmodus zu bleiben.

## Nachweise und Freigabe
Die neue Regression scheiterte auf V62.0.2: Nach Zugauswahl aus einer Verbindung erschien
der Planer. Tests prüfen jetzt beide Rückwechsel ohne Neuladen sowie beide Suchübergänge,
320/390/430/844/1440 Pixel, Radar-Teilausfall, HTTP 503, Wiederherstellung und Schließen.
Fixtures belegen UI-Verhalten, keine vollständige Anbieterabdeckung.
Vor Veröffentlichung müssen alle Workflows des endgültigen Commits erfolgreich sein.
Keine fehlgeschlagenen Tests deaktivieren oder übergehen.
