## 1. Produktziel — sichtbar, nicht nur umbenannt

**Abnahmeszenario:** Innerhalb von 30 Sekunden erkennt eine bestehende Person bei gleicher Beispielstation einen neuen Aufbau und kann ohne Einweisung (a) eine echte Abfahrt finden, (b) ein Fahrtdetail mit Prognose/Quelle öffnen und (c) die Fahrt auf der Karte sehen bzw. korrekt als "keine verifizierte Position" erkennen.

**Gestaltung:** Ein modernes, schlichtes Rail-Produkt statt vieler schweben­der Karten. Quiet-Rail-Richtung aus PR #88 erhalten und konsistent auf **Startseite, Suche, Bahnhof, Zugdetail, Verbindung, Radar, Favoriten und Einstellungen** anwenden. Glass-Effekt nur für Navigation, definierte Overlays und Follow-HUD; opaque Fahrplandaten und WCAG-konforme Kontraste. Weder pauschale Blur-Overrides noch zehn neue CSS-Themes. Bestehende alte V48–V62-Stilregeln bewusst prüfen und redundant/konfliktträchtig Gewordenes schrittweise konsolidieren.

### Geplante sichtbare Ergebnisse
- [ ] **V63 Design System:** konsistente Tokens für Farben, Typografie, Spacing, Focus, Surface, Elevation, Glas/Transparenz; responsive Desktop- und Mobile-Shell; Hell/Dunkel/High-Contrast/Reduced Motion/Reduced Transparency.
- [ ] **Neuer Startbereich:** klarer Weg „Bahnhof finden“/„Verbindung planen“, eigene Favoriten/Pendelstrecken sichtbar und unmittelbar ausführbar; Loading/Empty/Offline explizit. Keine Fake-Personalisierung.
- [ ] **Bahnhof 2.0:** flache lesbare Ankunfts-/Abfahrtszeilen, sticky Kopf, Linien-/Ziel-/Gleis-/Zeit-Hierarchie, Datenalter/Quellenstatus, ein gemeinsamer Filterbereich, Anzeige von Ausfall und Gleiswechsel aus Providerdaten.
- [ ] **Zugdetail 2.0:** nachvollziehbare Stop-Timeline mit Soll/Ist, Gleis, Verspätung, Datenquelle, Aktualisierungszeit, relativer ETA nur aus ausreichend frischen Werten; übersichtliche Aktionen Karte/Verfolgen/Schließen.
- [ ] **Radar 2.0:** klar unterscheidbare bestätigte Halte und dargestellte/geometrisch modellierte Positionen; Marker stabil und anwählbar, keine Fake-GPS-/Luftlinien. Alle providerbestätigten Bahnhofshalte bleiben auch ohne Kartenmarker in einer nutzbaren Liste zugänglich.
- [ ] **Follow-HUD 2.0:** eindeutige Start-/Stopp-Steuerung, Zugname, Ziel, aktuelle/erwartete Ankunft, Verspätung/Quellenfrische, Fortschritt nur wenn legitim, Fehler-/Wiederherstellungszustände. Web-Follow nur im zulässigen Browser-Lebenszyklus; echte persistente Android-Foreground-Notification nur als separat hardwareabgenommener nativer Release.
- [ ] **Reiseplaner 2.0:** Alternativen lesbar vergleichen, Abfahrt/Ankunft/Umstiege/Puffer/Gleis/Quellenfrische, unsichere Anschlüsse konservativ kennzeichnen. Keine sichere Verbindung ohne belegte Daten.
- [ ] **Störungen/Qualität:** eine konsistente Darstellung für Ausfall, Umleitung, Teilabdeckung, veraltete Abfrage, unbekannte Route; keine ungerechtfertigten grünen „Alles gut“-Signale.
