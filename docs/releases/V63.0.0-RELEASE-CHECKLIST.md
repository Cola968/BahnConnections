## Sichtbare und begrenzte Änderungen
- Ruhige Tafelzeilen statt schwebender Karten; reduziertes Glas nur für Navigation.
- Klarere Bahnhofstitel, Tabs, Abfahrten/Ankünfte, Statusfarben nach realen Daten.
- Halte-Monitor zeigt Datenabrufzustand, erlaubt gemeinsames Zurücksetzen aktiver Filter.
- Mobile Landscape Regression: mindestens eine vollständige Abfahrt; Browser-Test statt abgeschwächter Assertion.

**Nicht Teil dieses Web-MVP:** Neue Live-Datenquellen, neue geographische Positionen, native Android-Hintergrund-Benachrichtigungen, Stripe, Supabase-Migrationen. Diese Themen sind unabhängig zu prüfen.
