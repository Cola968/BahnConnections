## Google Play / direkter Start ohne Render-Ladeseite

- [x] Statische Prüfung `pnpm audit:play-hosting` und Hosting-Origin-Klassifizierung verhindert eine versehentliche Freigabe mit der kostenlosen `*.onrender.com`-Adresse.
- [x] Der Live-Smoke `pnpm smoke:play-start` prüft die **tatsächliche** Startadresse, Version, PWA, Service Worker und Google-Play-Digital-Asset-Links.
- [x] Die alte Sites-Domain ist nicht mehr fest als Metadaten-Origin hinterlegt; für neue Deployments ist `NEXT_PUBLIC_APP_ORIGIN` konfigurierbar.
- [ ] Einmalige GitHub-Verbindung in Cloudflare Workers Builds autorisieren und Worker `bahnconnections-standalone` wirklich bereitstellen.
- [ ] Eine echte, langfristig stabile Cloudflare-HTTPS-Origin auswählen; falls möglich eigene App-Subdomain statt eines temporären URL-Wechsels.
- [ ] Auf echter Worker-URL den Live-Smoke einschließlich signierter Android-Digital-Asset-Links erfolgreich ausführen.
- [ ] Google-Play-Paket-ID, Signing-Schlüssel-/SHA256-Fingerprint und Android-TWA oder nativen Wrapper festlegen; erst danach ein echtes signiertes `.aab` erzeugen.
- [ ] Android-Kaltstart nach über 20 Minuten Inaktivität: **sofort zur BahnConnections-Oberfläche, niemals Render-Aufwachseite**. Auch Offline-/Fehlerzustand und alle API-Routen prüfen.
- [ ] Bereits von der Render-Origin installierte PWAs müssen auf die neue App-Origin umgestellt bzw. von dort neu installiert werden; Origin-Wechsel wird nicht automatisch von einer alten PWA übernommen.

Anleitung: [Google Play ohne Render-Ladeseite](../deploy/PLAY-STORE-NO-RENDER-SPLASH.md).

## Veröffentlichung / Rückfall

GitHub `main` wird von Render automatisch für den Dienst `bahnconnections-v55` überwacht. Ein Merge kann deshalb eine öffentliche Bereitstellung auslösen. Nicht mergen, bevor Tests, Rechte und Abnahme bewusst freigegeben sind. Vorherige Render-Deployment-ID/SHA für Rollback sichern, danach `/version.json` auf `57.3` prüfen und funktionale Smoke-Tests ausführen.

**Grenzen:** Es gibt keine echte GPS-Telemetrie oder Push-Überwachung von Linien. Die Störungsansicht kennt nur Meldungen aus begrenzten Fahrplanabfragen; ein leerer Bildschirm beweist keine störungsfreie Netzlage.
