## Behoben und eingegrenzt

- #67: Rechteinhaber hat MIT für den eigenen Code ausdrücklich ausgewählt;
  LICENSE, Paketmetadaten und sichtbare Hinweise ergänzt. Keine Umlizenzierung
  von Fremddaten. Plus/Checkout bleiben deaktiviert.

  DB-Identität mit höchstens 50 m Distanz darf nun BUS-Quellen auflösen. Andere
  Busstopps, falsche Namen und mehrdeutige IDs bleiben ausgeschlossen. Bus ist
  keine Bahn oder automatisch bestätigter SEV; kein erfundener Kartenpunkt.
